# Dotka-controll-with-voice

*Полный гайд на использование этой программы, в котором будут все используемые кнопки. Слова которые выделенны нужно произносить, чтобы нажималась та или иная кнопка.*

**================= СКИЛЛЫ ГЕРОЯ =================**

  _q_ - `первый`

  _w_ - `второй`

  _e_ - `третий`

  _r_ - `ульт`

  _d_ - `четвертый`

  _f_ - `пятый`



**================= ДЕЙСТВИЯ ГЕРОЯ =================**

  _s_ - `стоп/стой`

  _a_ - `бить/атака` **авто атака**

  _space_ - `герой`

  _LBM_ - `клик`

  _RBM_ - `огонь`

  _f_ - `пятый`

**================= КУРЬЕР И МАГАЗИН =================**

  _f3_ - `принеси`

  _b_ - `магазин/лавка`

  _f4_ - `закуп`

**================= ПРЕДМЕТЫ =================**

  _z_ - `слот один`

  _x_ - `слот два`

  _c_ - `слот три`


**На этом всё, have fun.**
